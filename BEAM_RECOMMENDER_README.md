# Deep-learning beam-divergence recommender

This module trains a small NumPy multilayer perceptron on synthetic cases generated by the beam-propagation equations. It predicts effective half-divergence for each candidate beam and ranks the candidates.

## Current objective

“Best beam” means the beam with the smallest effective half-divergence at the requested propagation distance.

The current candidates are:

- Gaussian
- Bessel
- Airy
- Top-hat aperture
- Laguerre–Gaussian LG01
- Hermite–Gaussian HG10
- Bessel–Gaussian

The effective divergence is defined as a characteristic transverse width divided by propagation distance. This makes the beam families comparable, but it is not a universal definition for every beam. The final output reports both the neural prediction and the physics-calculated value; the physics value is used to verify the final winner.

## Train

```bash
cd /home/ubuntu/light_beam_divergence_sim
python3 beam_recommender.py
```

Training inputs include:

- wavelength
- waist radius
- beam quality `M²`
- propagation distance
- receiver/aperture scale
- Bessel cone angle
- Bessel generating aperture
- Airy scale
- beam-family one-hot encoding

The script writes:

- `outputs_beam_recommender/beam_recommender_model.pkl`
- `outputs_beam_recommender/beam_recommender_metrics.csv`
- `outputs_beam_recommender/beam_recommender_validation.png`
- `outputs_beam_recommender/example_recommendation.csv`

The generated training data are physics-based synthetic data, not measured experimental data. A future production model should be retrained using FFT diffraction simulations and measured beam profiles.

## Inference

```bash
python3 recommend_beam.py \
  --wavelength-nm 1064 \
  --waist-mm 10 \
  --m2 1 \
  --distance-km 100
```

The tool prints the physics-verified lowest-divergence beam, the MLP-predicted winner, and a complete ranking.

## Important physical caution

There is no universally best beam without constraints. A Bessel-like beam can have a narrow central core but requires a finite generating aperture and has a limited nondiffracting range. A larger initial aperture can also reduce divergence. Therefore, beam type, waist, cone angle, aperture size, wavelength, and propagation distance must be specified together.
